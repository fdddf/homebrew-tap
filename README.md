# fdddf/homebrew-tap

Homebrew formulae for [Spotless](https://github.com/fdddf/spotless-cli).

```bash
brew install fdddf/tap/spotless
```

Or, if you prefer to tap first:

```bash
brew tap fdddf/tap
brew install spotless
```

Then run `spotless` for the interactive TUI, or `spotless scan` to see what
could be reclaimed without changing anything.

## What's here

| Formula | What it installs |
|---|---|
| `spotless` | The Spotless CLI — a macOS cleaner for the terminal |

The formula points at the universal binary published by the CLI's own release
workflow, and is updated automatically when a new version is tagged there.
